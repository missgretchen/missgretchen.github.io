# Gretchen Eggers - Portfolio Website

A modern, edgy single-page portfolio website built with React and Vite, featuring a high-contrast red and light blue design.

## 🚀 Live Site

- **Custom Domain:** [https://gretcheneggers.io](https://gretcheneggers.io)
- **GitHub Pages:** [https://missgretchen.github.io/missgretchen.github.io/](https://missgretchen.github.io/missgretchen.github.io/)

## 🛠️ Tech Stack

- **React 18** - Modern React with hooks
- **Vite** - Fast build tool and development server
- **CSS3** - Custom styling with modern features
- **GitHub Pages** - Hosting and deployment
- **GitHub Actions** - Automated deployment

## 🎨 Design Features

- Light, modern design inspired by contemporary web aesthetics
- High-contrast red (#ff0040) and light blue (#00bfff) accent colors
- Glassmorphism effects with backdrop blur and subtle transparency
- Responsive design that works perfectly on all devices
- Smooth animations and hover effects
- Clean typography with proper spacing and hierarchy
- Social media icons with brand-specific hover states

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/missgretchen/missgretchen.github.io.git
   cd missgretchen.github.io
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 📝 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
- `npm run deploy` - Deploy to GitHub Pages (manual)

## 🔧 Customization

### Updating Content

1. **Profile Image:** Replace `public/Headshot.jpg`
2. **Resume:** Replace `public/resume.pdf`
3. **About Me:** Edit text in `src/components/Portfolio.jsx`
4. **Social Links:** Update the `socialLinks` array in `Portfolio.jsx`

### Styling

- Main styles: `src/components/Portfolio.css`
- Global styles: `src/index.css`
- Color scheme: Red (#ff0040) and Light Blue (#00bfff)
